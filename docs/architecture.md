# Griffitus Architecture

## Описание системы

Griffitus — это экосистема для удаленного управления устройствами пользователя.
Система состоит из трех основных компонентов:

1. Griffitus Mobile Application
2. Griffitus Backend API
3. Griffitus Agent

Основная задача системы — предоставить пользователю возможность управлять своими устройствами через мобильное приложение.

# Компоненты системы

# 1. Griffitus Mobile Application

Платформа:
iOS

Ответственность:

- Регистрация пользователя
- Авторизация
- Двухфакторная аутентификация
- Управление устройствами
- Просмотр состояния устройств
- Мониторинг системы
- Работа с файлами
- Отправка команд
- Управление сценариями
- Удаленное подключение

---

# 2. Griffitus Backend API

Платформа:

Node.js + Express

Ответственность:

- Обработка HTTP запросов
- Авторизация пользователей
- Управление JWT токенами
- Работа с базой данных
- Управление устройствами
- Обработка команд
- Отправка уведомлений
- Работа с WebSocket соединениями

---

# 3. Griffitus Agent

Платформа:

Windows

Ответственность:

- Установка на компьютер пользователя
- Регистрация устройства
- Поддержание постоянного соединения с сервером
- Передача информации о системе
- Выполнение команд пользователя
- Работа с файлами
- Управление питанием устройства
- Подготовка данных мониторинга

---

# Основной принцип работы

Пользователь взаимодействует с мобильным приложением.
Mobile Application отправляет запрос в Backend API.
Backend проверяет пользователя и создает необходимое действие.
Если действие связано с устройством:
Backend передает команду через WebSocket соединение Griffitus Agent.
Agent выполняет действие на компьютере.
Результат выполнения отправляется обратно в Backend.
Backend обновляет данные и отправляет результат пользователю.
