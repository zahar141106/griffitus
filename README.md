# GRIFFITUS
Griffitus - экосистема удаленного управления персональными устройствами 

Цель: 
Создать единное пространство, позволяющее пользователю контролировать свои устройства, получать информацию о состояниисистемы и авторизовывать рутинные задачи

## Основные модули приложения

-Griffitus mobile
-Griffitus API
-Griffitus Agent
-Griffitus AI
